# Как запускать эти тикеты

Один тикет — один свежий чат. По порядку номеров: 01, 02, 03, … 09.

## Что писать в новый чат

Скопировать целиком, поменять только путь к тикету в первой строке:

```
Тикет: .scratch/panel-rebuild/issues/01-english-only.md

Прочитай его, прочитай AGENTS.md и .scratch/panel-rebuild/spec.md, и сделай
тикет целиком — включая чеклист в конце файла.

Правила:
- main — это билд, который прямо сейчас крутится на сервере владельца.
  Работай на ветке от main, в конце влей в main.
- Тесты: python -m pytest -q --deselect tests/test_mta_ticket_02.py
  (этот модуль падает на этой машине до и после любой работы — не чини его)
- В конце разверни на сервер:
  C:\Games\MTA San Andreas 1.6\server\mods\deathmatch\resources\ankigta\
  Только файлы кода, в CRLF. Не трогай ankigta.sqlite, connection.json,
  backups/ и maps/ — это данные владельца.
- Никаких других тикетов. Заметил проблему рядом — запиши в тикет, не чини.

Доложи в конце: что сделал, что из чеклиста осталось непроверенным вживую.
```

## Когда чат закончил

1. Зайти в игру и посмотреть — тикет для этого и делался.
2. Работает — вернуться в главный чат, сказать «01 готов», взять следующий.
3. Не работает — сказать об этом **в том же чате**, он ещё в контексте.

Не открывать следующий тикет, пока предыдущий не посмотрен в игре. В этом весь
смысл: прошлый раз четыре ветки шли разом, и владелец полдня судил о фичах по
билду, который отставал на два тикета.
