# 32 — One CEF panel, and no study menu

**What to build:** Один игровой интерфейс — локальная CEF-панель по F7 с секцией подключения, рабочей областью Map Entity и настройками, вместо россыпи CEGUI-окон. Сессия поднимается сама, окно обучения исчезает.

**Blocked by:** 31 — Packaging and release certification (влит; переезд идёт поверх сертифицированного поведения, не вместо него).

**Status:** in-progress

**Environment boundary:** Follow `AGENTS.md` and `docs/agents/mta-gta-reference-policy.md`. Verify programmatically — launching disposable copies is allowed, driving a GUI with screenshots or synthetic input is not, and the installed MTA/GTA tree stays unmodified. Acceptance that only a human can observe stays a manual checklist marked `not run`.

## Почему

Владелец назвал прежние ресурсы `anki_map_editor` и `anki_in_gta` как образец
интерфейса. Их устройство: **одна панель по F7, один локальный CEF-браузер**, а
внутри — секция подключения (`connection-gate`: порт, токен, таймаут,
«Подключиться и продолжить» / «Закрыть без подключения») и рабочая область
(список объектов, активные/архив, «Выбрать в игре», телепорт, радиус, связать/
отвязать, поиск карточек «сначала колода», инспектор карточки). Повторение —
второй CEF-экран тем же механизмом. Меню обучения не было вообще.

v1 вместо этого набрал восемь CEGUI-окон: F7, Card Picker, два подтверждения,
подключение, настройки, масштаб, восстановление — плюс окно обучения.

Меню обучения возникло из `ANKIGTA Session`: раз есть filtered deck, которой
владеет add-on, у неё есть жизненный цикл, и он оказался вынесен в кнопки Start
/ Pause / Rebuild / Stop. Сессия нужна — она следствие Exact Card Admission, —
но **кнопки не нужны**: сессия может подниматься при подключении и убираться,
когда открылся штатный Reviewer или упало соединение. Пользователю нужна одна
строка состояния, а не четыре кнопки.

## Acceptance criteria

- [ ] Сессия поднимается автоматически при живом подключении и активных Spatial Link, перестраивается при изменении Active Map Set и убирается при открытии штатного Reviewer, потере связи и остановке ресурса. Ни одна карточка не остаётся в filtered deck, которой владеет ANKIGTA.
- [ ] Окно обучения удалено вместе с событиями start/pause/rebuild/stop/cancel, идущими от клиента. Состояние обучения видно в HUD.
- [x] F7 открывает одну локальную CEF-панель. Пока подключения нет, она открывается на секции подключения; «Закрыть» доступно всегда — и клавишей Escape. Браузер создаётся локальным: у remote мост `window.mta` не работает, и панель отрисовалась бы глухой.
- [x] Порт и токен правятся в этой же панели. `client/connection_settings.lua` удалён вместе с обоими своими окнами; команды `ankigta-connect` и `ankigta-connection` перешли на панель.
- [ ] Рабочая область панели даёт то же, что давали CEGUI-окна: список Map Entity с состоянием Spatial Link, Card Picker с фильтром колоды, Unlink, Replace card, Relink entity, Pick Entity, Undo/Redo, решение о копии карты, Pending Map Save и повторная проверка.
- [ ] Настройки и UI Scale — секции той же панели; отдельных окон нет.
- [ ] Экран восстановления базы (тикет 29) остаётся достижимым и когда панель не открывается.
- [x] Локализация панели идёт из `shared/locale.lua`: Lua шлёт словарь целиком, английский подложен под активный язык. Разметка несёт только `data-i18n`-ключи, и тест доказывает, что единственный текстовый узел в HTML — само слово ANKIGTA.
- [x] Мост Lua↔JS работает только для локальной страницы. Контент карточки остаётся в своём браузере и моста не получает (прототип 0006: `window.mta` подмешивается в каждый V8-контекст, а browser-process отбрасывает `TriggerLuaEvent` только у remote-браузера).
- [~] UI Scale действует на размер панели. Размещение (перетаскивание, сохранение позиции) — нет: панель не CEGUI-окно, и `Layout` ей пока не владеет.

## Components

- Локальная CEF-панель: HTML, CSS, JS.
- Мост Lua↔JS и клиентский контроллер вместо восьми окон.
- Автоматический жизненный цикл `ANKIGTA Session`.

## Порядок, который имеет значение

Удалять окно обучения **до** автоподъёма сессии нельзя: это единственный
существующий способ её начать, и удаление оставит игрока без обучения. Сначала
автоподъём, потом удаление окна.

Панель переносится по секциям, и каждая секция снимает своё CEGUI-окно в том же
изменении, а не «потом»: две реализации одного экрана одновременно — это два
места, где чинить один баг.

## Сделано в первом заходе

Каркас панели и секция подключения. `client/panel.lua` владеет состоянием и
шлёт его целиком; страница ничего не решает и не хранит. Прежнее окно
подключения снято в этом же изменении, как требует правило ниже.

Палитра взята не из старого ресурса, а из тёмной схемы «Digital Signage /
Kiosk» дизайн-базы: поверхность, которую читают мельком и при разном
освещении, — это и есть оверлей поверх игрового мира. Акцент заменён с красного
на sky: красный здесь уже значит отказ, и акцент того же цвета превратил бы
каждую кнопку в предупреждение. Состояние связи несёт слово, а не только цвет.

Два дефекта прежней попытки, названные владельцем, закрыты тестами, а не
обещанием: курсор возвращается на каждом пути выхода (закрытие, остановка
ресурса, отзыв прав, несозданный браузер) и не отбирается, если он уже был
показан; список Map Entity упорядочен по состоянию связи и имени, а не по
идентификатору, и порядок полный — две строки не меняются местами между
отрисовками.

## Осталось

Рабочая область пока только показывает список. Не перенесены: Card Picker,
Unlink, Replace card, Relink entity, Pick Entity, Undo/Redo, решение о копии
карты, повторная проверка Pending Map Save, настройки, UI Scale и экран
восстановления — вместе со снятием их CEGUI-окон. Автоподъём сессии и удаление
окна обучения тоже впереди; до них окно обучения остаётся и продолжает
открываться по статусу.
