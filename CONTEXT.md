# ANKIGTA

ANKIGTA связывает обучение в Anki с пространством игрового мира MTA:SA. Расположение игровых сущностей служит частью запоминания, а Anki остаётся системой интервального повторения.

## Language

**Map Entity**:
Созданная через MTA Map Editor сущность поддерживаемого типа: object, vehicle, ped или marker. Её постоянная идентичность не зависит от текущего живого экземпляра.
_Avoid_: Object, когда имеются в виду также vehicle, ped и marker

**Runtime Instance**:
Текущий живой экземпляр Map Entity в загруженном игровом мире. Он может двигаться или быть уничтожен, не удаляя саму Map Entity и её сохранённую связь.
_Avoid_: Map Entity, когда речь только о текущем живом экземпляре

**Entity Missing**:
Состояние сохранённой Map Entity, для которой больше не находится соответствующая сущность в данных карты. Оно отличается от временно уничтоженной Runtime Instance.
_Avoid_: Object missing, когда типом может быть vehicle или ped

**Pending Map Save**:
Состояние подготовленной Spatial Link для Map Entity, постоянные ID которой ещё не подтверждены повторным чтением после штатного сохранения Map Editor. Такая связь не считается активной для обучения; после Save ANKIGTA проверяет её автоматически, а при неудаче пользователь может запустить проверку повторно.

**Pick Entity**:
Временный режим выбора прогруженной управляемой Runtime Instance непосредственно в игровом мире с последующим переходом к её Map Entity в F7.
_Avoid_: Pick object

**Spatial Link**:
Сохранённая связь между Map Entity и одной конкретной Anki Card. Одна Map Entity имеет не более одной Spatial Link, а одна Anki Card может быть связана с несколькими Map Entity.
_Avoid_: Note Link, Language Item Link

**Text Label**:
Надпись в мире, которую Spatial Link показывает возле своей Map Entity в Review Mode `Show text`. Несёт поле заметки, цвет и размер; у каждого из трёх есть глобальное значение и переопределение на самой связи. Text Label — не предъявление Anki Card: в этом режиме карточку нельзя ни открыть, ни оценить (ADR 0029). Текст кэшируется в базе ANKIGTA и является копией для показа, а не источником истины.
_Avoid_: 3D text, подпись, world text

**Entity Tag**:
Пользовательская метка Map Entity, принадлежащая ANKIGTA и используемая для организации игрового мира.
_Avoid_: Anki Tag, Tag без уточнения

**Anki Tag**:
Нативная метка note в Anki, которую ANKIGTA только читает вместе с остальными данными карточки.
_Avoid_: Entity Tag, Tag без уточнения

**Change History**:
Сохраняемая история последних 100 пользовательских изменений данных ANKIGTA, используемая для многошаговых Undo и Redo. В неё входит только то, чем владеет сервер: Undo работает тем, что сервер переписывает хранимое им состояние, поэтому настройки клиента и add-on — язык, UI Scale, UI Placement, звук, подключение — в историю не попадают (ADR 0028), как и внешние изменения Anki или игрового мира.
_Avoid_: Link History

**Anki Card Identity**:
Пара из идентичности коллекции Anki и `cardId`. Одинаковые числовые `cardId` из разных коллекций не обозначают одну карточку.
_Avoid_: cardId без контекста коллекции

**Collection Copy Decision**:
Одноразовый выбор при обнаружении скопированного collection UUID: `Это прежняя коллекция` сохраняет существующую идентичность и Spatial Link, а `Это новая копия` назначает новый UUID и начинает без связей. Если прежний экземпляр всё ещё зарегистрирован на компьютере, копия автоматически считается новой; выбор прежней коллекции доступен только для переноса или восстановления отсутствующего экземпляра.

**Bound Anki Collection**:
Единственная коллекция Anki, с которой работает v1 ANKIGTA. Ею автоматически становится первая коллекция, которую увидел companion add-on: выбирать нечего, пока не появилась вторая. При открытии другой коллекции обучение приостанавливается и пользователь получает уведомление: связи не переносятся, совпавшие `cardId` не сопоставляются, а незавершённые Review Transaction остаются привязаны к исходной коллекции. Привязка существует ради этого случая, а не ради шага настройки.

**Companion Connection**:
Локальное соединение между server-side Lua MTA Server и companion add-on в уже запущенном пользователем Anki Desktop. В v1 используется только numeric IPv4 loopback `127.0.0.1`, подтверждённый Prototype 0004; IPv6 `::1` не поддерживается. Companion add-on владеет автоматически создаваемой конфигурацией подключения и после однократного выбора папки MTA-ресурса атомарно публикует её в локальный connection file; MTA Server читает этот файл. В дополнительных настройках обеих сторон остаются поля для ручной замены порта и токена. Ручное значение включает Manual Connection Mode на соответствующей стороне: оно не перезаписывается автоматикой, а несовпадение значений даёт явную ошибку до возврата обеих сторон в Automatic Connection Mode либо ручного согласования. Это не `ANKIGTA Session`: подключение и переподключение сами не запускают обучение, не создают filtered deck и не открывают Review Mode.
_Avoid_: Игровая сессия

**Transport Request**:
Одна логическая операция обмена между server-side Lua и companion add-on, имеющая устойчивый `requestId`. Для оценки Transport Request также несёт отдельный `reviewTransactionId`, который сохраняется при потере ответа и сверке.
_Avoid_: Review Transaction

**Card Picker Deck Filter**:
Выбранная пользователем колода Anki, которой первоначально ограничен список Card Picker. Это только фильтр поиска, а не граница Spatial Link или `ANKIGTA Session`; уже связанную карточку не отключает её перенос в другую колоду.
_Avoid_: Session deck scope, Bound deck

**Unavailable Card**:
Существующая Anki Card, временно исключённая из оценивания состоянием `Suspended` или `Buried`. Она отлична от удалённой карточки и остаётся доступной для Preview only.
_Avoid_: Card missing, Not due

**Not-due Card**:
Review-карточка, существующая и доступная в Anki, но ещё не достигшая следующего срока. В Review Mode `Allow due` ANKIGTA открывает её только как Preview. Review Mode `Allow all` допускает штатную early-review оценку через Anki с явным предупреждением и включает карточку в `ANKIGTA Session` и пространственную активацию.
_Avoid_: Unavailable Card, `Разрешить досрочное повторение`

**Review Transaction**:
Одна попытка оценить конкретную scheduler-admitted Anki Card, имеющая устойчивый `reviewTransactionId`. После сбоя companion add-on автоматически восстанавливает и сверяет её: уже принятую оценку не повторяет, а доказанно непринятую доотправляет с тем же ID. Пока исход неизвестен, повторно оценивается только после дальнейшей сверки, чтобы не создать двойную запись.

**Outcome Unknown**:
Состояние Review Transaction, в котором пока нельзя доказать ни применение, ни неприменение оценки. Такая транзакция не повторяется вслепую, не переносится в другую коллекцию и блокирует только затронутую карточку.

**Scheduler-admitted Card**:
Anki Card, которую штатный планировщик Anki признал текущей допустимой карточкой для оценивания. Возможность отрендерить точную карточку по ID сама по себе не делает её scheduler-admitted.
_Avoid_: Exact Card, когда речь о допустимости оценки

**Review Mode**:
Модальное состояние с открытой Anki Card, в котором ANKIGTA передаёт ввод интерфейсу повторения и подавляет собственные игровые горячие клавиши. Потеря фокуса не завершает Review Mode и не создаёт оценку.

**Review Mode (настройка)**:
Настройка, задающая, какие карточки берёт обучение: `Allow due` — только те, которые планировщик Anki считает подошедшими, `Allow all` — независимо от срока. Третье значение `Show text` (ADR 0029) вместо предъявления карточки рисует Text Label. Заменила булеву настройку `Разрешить досрочное повторение`, чьё имя не описывало ни одного из двух своих состояний. Одно имя на два понятия — состояние экрана и выбор состава обучения — здесь намеренно: так эту настройку назвал владелец, и ticket 05 уже ссылается на неё этим именем.

**External Card Page**:
Внешняя страница, на которую stock MTA CEF перешёл внутри карточной поверхности Review Mode. Оценивание остаётся доступным; действие `Вернуться к карточке` заново загружает текущую сторону Anki Card.
_Avoid_: Review Mode, System browser

**Supported Card**:
Anki Card, предъявляемая в stock MTA CEF в режиме best effort. v1 не обещает точного визуального или поведенческого совпадения с Anki Desktop; ошибки HTML, JavaScript, шаблона или медиа показываются как предупреждение, но не блокируют оценивание.
_Avoid_: Pixel-perfect Card

**Activation Zone**:
Физическая сфера в игровом мире вокруг доступного Runtime Instance, внутри которой возможно пространственное взаимодействие. Радиус задаётся в диапазоне 0,5–50 метров; это не отметка на карте.
_Avoid_: Зона на миникарте, Map marker

**Minimap Blip**:
Отметка положения цели на миникарте. Она отлична от Activation Zone.
_Avoid_: Activation Zone

**Next Card Indicator**:
Настраиваемое отображение цели, выбранной следующей планировщиком Anki: Minimap Blip вместе с Activation Zone, только Minimap Blip либо отсутствие отметки.
_Avoid_: Due marker

**Active Map Set**:
Загруженные карты с валидной идентичностью, для которых включено `Include in study`. Выгрузка или исключение карты не удаляет её сохранённые связи.

**ANKIGTA Session**:
Временная rescheduling filtered deck, построенная и целиком управляемая companion add-on из уникальных Anki Card активного игрового мира. На протестированной версии Anki она используется и как обычная полная сессия, и временно перестраивается в набор из одной точной карточки для её штатного допуска планировщиком. В неё входят все связанные новые карточки независимо от дневного лимита исходной колоды; карточка сверх сегодняшнего лимита остаётся доступной для оценки, но явно помечается в Review Mode.

Стандартный Anki Reviewer и `ANKIGTA Session` являются взаимоисключающими режимами обучения. Запуск обычного повторения в Anki ставит ANKIGTA на паузу и очищает её filtered deck; автоматического возврата к игровому обучению нет.

**Exact Card Admission**:
Подтверждённая для Anki 26.05 последовательность: companion add-on перестраивает принадлежащую ANKIGTA filtered deck в точный набор из Card X, проверяет, что штатный планировщик Anki вернул X как scheduler-top, применяет оценку через Anki и затем перестраивает полный набор сессии. Порядок `cardId` в широком наборе не управляет scheduler-top.

**Review Protection**:
Отдельный от блокировки управления режим, предотвращающий новый урон игроку и занятому им автомобилю во время открытого повторения.
_Avoid_: Disable player controls

**UI Scale**:
Клиентская настройка размера всего интерфейса ANKIGTA от 0.5 до 2 с двумя знаками после запятой; кнопки меняют её шагом 0.05, а точное значение вводится вручную. Она применяется сразу ко всем открытым окнам и к HUD. Поверхность крупнее экрана уменьшается при отрисовке до размеров экрана, чтобы заголовок и кнопки оставались доступны; сама сохранённая настройка при этом не меняется.
_Avoid_: Font size, Zoom

**UI Placement**:
Сохранённое положение подвижных поверхностей в долях экрана, а не в пикселях, поэтому одно и то же значение означает одно и то же место на 1280×720 и на 3840×2160. Принадлежит клиенту и не входит в Change History; возврат к исходному состоянию делает `Reset UI layout`.
_Avoid_: Window coordinates

**Edit HUD layout**:
Режим, в котором HUD со счётчиками можно перетаскивать мышью. Вне этого режима HUD не двигается: у него нет заголовка, и без отдельного режима любой клик рядом со счётчиками мог бы их сдвинуть. F7 и Review Mode перетаскиваются за заголовок и такого режима не требуют.
_Avoid_: HUD editor

**Study Player**:
Единственный администратор MTA, которому доступны интерфейс, пространственное обучение и локальная коллекция Anki. ANKIGTA не имеет многопользовательского учебного режима.
_Avoid_: Любой подключённый игрок

**Total**:
Число уникальных доступных сейчас карточек в объединении New, Learning, Due и Early. Одна карточка, связанная с несколькими сущностями, учитывается один раз.
_Avoid_: Remaining

**Early**:
Число уникальных Not-due Card, включённых в обучение Review Mode `Allow all`.
