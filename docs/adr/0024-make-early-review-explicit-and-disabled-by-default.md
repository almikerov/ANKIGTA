# Make early review explicit and disabled by default

> Имя настройки заменено. Panel-usability ticket 04 сделал её `Review mode` со
> значениями `Allow due` и `Allow all`: булево имя `Разрешить досрочное
> повторение` не описывало ни одного из двух своих состояний. Решение ниже
> действует целиком — меняется только то, как настройка называется. Значение по
> умолчанию — `Allow due`, то есть Preview only, — остаётся тем, что этот ADR
> принял. Владелец подтвердил замену имени 2026-08-04.

Not-due Card по умолчанию не оценивается в ANKIGTA: ручное открытие показывает Preview only без Again/Hard/Good/Easy. Пользователь может включить настройку `Разрешить досрочное повторение`; тогда карточка проходит Exact Card Admission, оценивается штатным планировщиком Anki и показывает предупреждение, что срок ещё не наступил.

При включённой настройке Not-due Card является полноценным участником обучения: входит в `ANKIGTA Session`, получает Activation Zone и Next Card Indicator и может открываться автоматически при приближении. При выключенной настройке она не входит в сессию и не активируется автоматически.

Статистика содержит отдельный счётчик `Early` для уникальных Not-due Card, включённых в обучение. `Total` объединяет `New`, `Learning`, `Due` и `Early`.

Счётчик `Early` отображается всегда. При выключенной настройке или отсутствии Not-due Card он показывает `0`, поэтому состав и расположение блока статистики не меняются.

Prototype 0002 подтвердил для Anki 26.05, V3 scheduler и FSRS, что future review в rescheduling filtered deck получает четыре штатные оценки и совпадает с контрольным supported early-review filtered deck. Поддержка остаётся версионно ограниченной. Настройка никогда не разрешает оценивание Suspended или Buried карточек.
