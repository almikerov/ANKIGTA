# Do not support gamepads

ANKIGTA поддерживает только клавиатуру и мышь; навигация, подсказки, переназначение и обработка ввода геймпада не входят ни в v1, ни в планируемые будущие версии. Подключённый контроллер не должен вызывать случайные действия или мешать CEF, но отдельный UX для него не создаётся.
