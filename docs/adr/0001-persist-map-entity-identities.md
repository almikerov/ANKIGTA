# Persist Map Entity identities through a verified map save

ANKIGTA автоматически присваивает Map Entity постоянный уникальный ID и записывает его в данные карты только через проверяемое штатное сохранение Map Editor; `.map` не редактируется в фоне. До повторного чтения и подтверждения ID подготовленная связь имеет статус Pending Map Save и не участвует в обучении; несохранённая или конфликтующая запись не активируется. Координаты и модель не используются как идентичность: сущности могут двигаться, разрушаться и позднее появляться снова, не теряя Spatial Link.

Prototype 0005 завершился `failed`, после чего принято использовать stock MTA Map Editor без fork и без гарантии атомарности или защиты от внешнего изменения. Поддерживаемый element-data/EDF serialization path для entity ID сохраняется; clone копирует custom ID, поэтому ANKIGTA обнаруживает дубли и не активирует их. Никакая связь не выходит из Pending Map Save без независимого read-back, а фоновая XML-запись не допускается.
