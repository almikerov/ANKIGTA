# Restrict ANKIGTA to the MTA Admin

ANKIGTA — однопользовательский продукт: F7, карточки, Spatial Link, HUD, зоны, маркеры и companion add-on доступны только вошедшей учётной записи с административным правом MTA ACL. Обычные игроки не являются Study Player и не получают функции ANKIGTA; независимые коллекции, личные связи и многопользовательский учебный режим не поддерживаются и не планируются.
