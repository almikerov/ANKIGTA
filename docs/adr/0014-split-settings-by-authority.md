# Split settings by authority

Server SQLite владеет сохранённым состоянием мира, обучения и Change History; MTA client владеет локальным представлением, вводом и звуком; companion add-on владеет автоматически создаваемой connection config и атомарно публикует её в локальный файл MTA-ресурса, который MTA Server читает. В дополнительных настройках обеих сторон пользователь может вручную заменить порт и токен для диагностики или восстановления. Состояние карточек разделяется по коллекции Anki, но обычные пользовательские настройки остаются общими; настройки подключения и размещение UI исключены из Change History.

Manual Connection Mode является явным локальным override и имеет приоритет над автоматически опубликованным значением только на своей стороне. Расхождение effective config считается ошибкой, а не конфликтом, который можно разрешить автоматическим выбором победителя.

Connection file не входит в защищаемый секретный vault: локальные программы и администратор Windows находятся внутри доверенной границы v1. Его права ограничиваются обычными средствами Windows, а значение токена редактируется только через настройки и редактируется/диагностируется без вывода прежнего секрета.

Prototype 0004 доказал транспорт с согласованным disposable port/token config, но не доказал production atomic publication. Продуктово выбран один authority — companion add-on — и один публикуемый connection file в MTA resource. Commit/recovery contract: временный файл → полная проверка → atomic replace; хранится одна предыдущая подтверждённо рабочая версия; MTA проверяет format/version/protocol identity и при непригодной новой версии откатывается к предыдущей с явной ошибкой. Реализация этого контракта всё ещё требует технического доказательства.
