# Create automatic rotating database backups

ANKIGTA автоматически создаёт backup SQLite перед каждой миграцией и не чаще одного раза в сутки после изменений, сохраняя семь ежедневных и три предмиграционных копии. Повреждённая база никогда не заменяется молча: пользователь выбирает проверенную копию на отдельном recovery-экране, а исходный повреждённый файл сохраняется для диагностики; connection config и размещение UI в backup не входят.
