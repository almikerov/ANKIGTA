# Scope card links to Anki collections

Spatial Link хранит Anki Card Identity, состоящую из идентичности коллекции и `cardId`. Переключение профиля временно деактивирует связи другой коллекции, а совпавший `cardId` из другой коллекции никогда не принимается за ту же карточку.

Prototype 0003 доказал, что разные профили могут содержать одинаковый числовой `cardId`. Add-on-owned UUID в collection config различал их и пережил перезапуск и переименование профиля. Имя профиля, путь и один `cardId` опровергнуты как безопасная идентичность.

В Anki 26.05 не найден нативный collision-resistant collection UUID, поэтому ANKIGTA использует add-on-owned UUID в collection config.

При обнаружении копии с уже известным UUID пользователь делает Collection Copy Decision. `Это прежняя коллекция` сохраняет UUID и существующие Spatial Link. `Это новая копия` назначает новый UUID и начинает без связей; этот вариант выбран по умолчанию. Эвристический перенос связей между двумя идентичностями запрещён.

Если экземпляр с этим UUID всё ещё зарегистрирован на компьютере, дубликат автоматически получает новый UUID и не может объявить себя прежней коллекцией. Вариант `Это прежняя коллекция` предлагается только когда ранее зарегистрированный экземпляр больше не найден, например после переноса или восстановления.
