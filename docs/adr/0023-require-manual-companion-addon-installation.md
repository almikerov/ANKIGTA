# Require manual companion add-on installation

Пользователь самостоятельно устанавливает и обновляет companion add-on в Anki. ANKIGTA не изменяет каталог add-on, не загружает пакеты, не добавляет команду установки и не перезапускает Anki ради установки или обновления.

Если add-on отсутствует или не отвечает, ANKIGTA показывает обычную ошибку соединения. Отдельной проверки версии add-on, таблицы совместимости и специального экрана обновления нет. Автоматический запуск уже установленного Anki Desktop при первоначальном подключении остаётся отдельным поведением и не означает управление установкой add-on.
