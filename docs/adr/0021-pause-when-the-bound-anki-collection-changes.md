# Pause when the bound Anki collection changes

Пользователь явно выбирает Bound Anki Collection во встроенной настройке ANKIGTA. v1 работает только с ней. Пока открыта другая коллекция, ANKIGTA приостанавливает обучение.

Связи не переносятся и не сопоставляются по одному `cardId`, `ANKIGTA Session` для другой коллекции не создаётся, оценки в неё не отправляются. Незавершённая Review Transaction сохраняется и автоматически сверяется только после возвращения Bound Anki Collection. Остальные игровые возможности, не изменяющие Anki, могут оставаться доступными.

Встроенный выбор колоды не привязывает ANKIGTA к колоде: это только начальный Card Picker Deck Filter. Перемещение связанной карточки между колодами не ломает Spatial Link и не исключает карточку из сессии.

Прямое открытие или изменение файлов чужого профиля запрещено.

Prototype 0003 показал A → B → A через штатный non-private AQT lifecycle, но в Anki 26.05 не нашёл документированного add-on API для программного выбора профиля. Поэтому прежнее предположение о поддерживаемом автоматическом переключении опровергнуто.

Принятый fallback: ANKIGTA не запускает Anki Desktop и не переключает профиль. Пользователь сам открывает Anki с нужным профилем. Companion Connection после этого устанавливается автоматически либо кнопкой `Подключиться`.

Переключение всегда упорядочено относительно Review Transaction. Если оценка уже отправлена, companion add-on сначала автоматически завершает её сверку: подтверждает уже принятую либо доотправляет доказанно непринятую. `Outcome Unknown` запрещает переключение и остаётся привязанным к исходной коллекции.

Если Anki Desktop не запущен либо закрывается после подключения, ANKIGTA восстанавливает игровые управление и звук, приостанавливает обучение и просит пользователя открыть Anki самостоятельно. Незавершённая Review Transaction сохраняется для последующей сверки.

После того как пользователь сам открыл Anki, ANKIGTA автоматически обнаруживает companion add-on, восстанавливает Companion Connection и начинает сверку. Одновременно в состоянии отключения всегда доступна кнопка `Подключиться`, запускающая немедленную ручную попытку; наличие кнопки не отключает автоматическое обнаружение.

Успешное переподключение не возобновляет обучение автоматически. После обязательной сверки незавершённой Review Transaction ANKIGTA остаётся на паузе, не создаёт `ANKIGTA Session`, не включает пространственные активации и не открывает прерванный Review Mode. Пользователь запускает обучение сам.

Обычный первоначальный запуск следует тому же правилу: Companion Connection устанавливается автоматически, но обучение начинается только после явного действия пользователя `Начать обучение`.

При выходе из MTA или штатной остановке ресурса ANKIGTA очищает собственную filtered deck и закрывает Companion Connection, но не завершает процесс Anki Desktop.

Prototype 0004 подтвердил транспортную часть lifecycle: absent companion, disconnect, automatic/manual reconnect, resource restart, harness restart, MTA restart и port change завершались bounded callback и оставляли studying/session/Review Mode выключенными. Full MTA restart не сохраняет Lua callback/socket; восстановление идёт по durable `reviewTransactionId`.
