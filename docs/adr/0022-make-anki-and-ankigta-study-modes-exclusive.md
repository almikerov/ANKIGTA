# Make Anki Reviewer and ANKIGTA study modes exclusive

Стандартный Anki Reviewer и обучение через ANKIGTA не работают одновременно с одной коллекцией. Если во время активного обучения ANKIGTA пользователь начинает обычное повторение в Anki, companion add-on автоматически ставит ANKIGTA на паузу, очищает `ANKIGTA Session` и возвращает карточки в исходные колоды.

Открытая карточка без отправленной оценки закрывается без изменения расписания. Уже отправленная Review Transaction сначала безопасно сверяется; стандартному Reviewer не передаётся управление очередью до завершения этой сверки и очистки filtered deck.

После окончания обычного повторения ANKIGTA не возобновляется автоматически. Пользователь снова запускает её явным действием `Начать обучение`.

Prototype 0003 показал, что переход в `deckBrowser` быстро закрывает question/answer без оценки и мутации, но этот AQT surface не является документированным add-on API. Для уже начатой асинхронной оценки немедленный cleanup небезопасен: backend создал ровно один `revlog`, однако stock callback продолжал зависеть от очищенного `Reviewer.card`.

Следовательно, прежнее предположение «всегда немедленно закрыть Reviewer и закончить оценку в фоне» опровергнуто. Если оценка уже началась, ANKIGTA показывает `Завершаем оценку Anki…`, оставляет Reviewer state нетронутым до завершения штатного callback и только затем автоматически закрывает Reviewer и создаёт `ANKIGTA Session`. Если callback не завершился, сессия не создаётся; timeout не разрешает принудительный cleanup. Monkey-patching callback, private UI mutation и принудительная отмена запрещены.
