# Allow linked new cards beyond Anki daily limits with a warning

`ANKIGTA Session` включает все новые карточки, связанные с Active Map Set, даже если исходная колода Anki уже исчерпала дневной лимит новых карточек. Такая карточка открывается и оценивается через штатный планировщик Anki, но Review Mode явно предупреждает: `Новая карточка вне сегодняшнего лимита Anki`.

ANKIGTA не вводит собственный дневной лимит новых карточек и не пытается воспроизвести лимиты исходных колод. Дневной лимит влияет только на наличие предупреждения, а не на допуск карточки.
