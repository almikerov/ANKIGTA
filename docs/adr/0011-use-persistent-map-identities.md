# Use persistent identities for maps

Каждая управляемая карта получает постоянный `ankigtaMapId`, сохраняемый тем же проверяемым процессом, что и ID сущностей. Переименование не меняет идентичность; при обнаружении скопированной карты с тем же ID пользователь выбирает, является ли она переименованным оригиналом или новой копией с новыми ID и без автоматического переноса связей.

Prototype 0005 подтвердил, что stock Editor не сохраняет произвольный `ankigtaMapId` на корне `<map>` при round-trip. В v1 используется отдельный EDF custom child element. Clone/copy сохраняют embedded ID, поэтому ANKIGTA блокирует коллизию до выбора пользователя и повторного штатного сохранения; отдельный fork Editor не создаётся.
