# Teleport directly without searching for a safe landing point

Команда Teleport переносит игрока непосредственно к выбранной сущности без поиска свободной поверхности и без запрета воды, пустоты, коллизий или салона автомобиля. Если игрок находится в автомобиле, переносится весь автомобиль вместе с пассажирами; для недоступной Runtime Instance используются исходные координаты, interior и dimension из карты.
